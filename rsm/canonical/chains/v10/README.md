## What Candidate 9 Establishes and Locks Down

### The Foundational Chain from P₀ to Recursion

Absolute Void (|0| :: 恆亡 :: 常無) and Absolute Not-Void (|1| :: 恆又 :: 常有) are the two
unreachable terminal faces of Absolute Indistinction (P₀ :: 玄牝, the Generative Paradox).

Because an infinite Reality has neither a final inside nor a final outside, neither |0| nor |1| can
obtain. What stretches between them is the infinite asymptotic gradient:

$$ \text{Void} \longleftrightarrow \text{Not-Void} \quad :: \quad \text{天拖} \quad :: \quad \text{天地} \quad :: \quad G_1 \quad :: \quad XY = 1. $$

To obtain the distinction between Void and Not-Void along this gradient requires a shared origin
reference where the axes meet:

$$ \text{無名 [天地之始]} \quad :: \quad O_n = \{\mathrm{xAxis}_n \cap \mathrm{yAxis}_n\} = (0,0), $$

which serves as the "no" in the contrast between thing and no-thing ($1_n \neq 0_n$).

Held by $O_n$, the gradient curve $G_n$ (有名 [萬物之母] :: 1ₙ) supports the infinite scattering
things (萬) and the cutting boundaries (勿) that separate them.

At the center of $G_n$ is the point where $\text{Void} = \text{Not-Void}$ ($x_n = y_n = 1$). It is
the held boundary (曰) that must exist as the reference defining the contrast, yet cannot obtain as
an operative state because $\text{Void} = \text{Not-Void}$ is Indistinction. That both must hold
simultaneously defines Local Paradox (Pₙ :: 玄).

Under the isometric logarithmic map
$\Phi_n(x_n,y_n) = \left(\frac{1}{2}\ln(x_n/y_n), \frac{1}{2}\ln(x_n y_n)\right)$, the parent's
local paradox $P_n(1,1)$ becomes the child's origin reference $O_{n+1}(0,0)$ (玄之又玄，眾妙之門).
Following paradox down into paradox infinitely without ever reaching a bottom is the Generative
Paradox (玄牝 :: P₀).
