## 1. Set A is not stale. It is the pre-strike register, wholesale.

`dao_ch1_translation.md` reads chapter 1 as **"operational documentation," "a consciousness-reality
interface system," "lost technology," "reverse-engineering," and classical translation as
"unintentional encryption."** It is built on machinery the framework has since struck by name:

- **P₀ as a field with a time derivative** — `∂P₀/∂t|eternal = 0`, `Ψ_paradox = α|frameless⟩ + β|framed⟩`, `Ĥ_obs = Ĥ_substrate + γ(desire-state)`. The physics chain's *not carried over* list names exactly this: *"any action functional taking a gradient of P₀, which treats an impossibility as a field; any typing of P₀ as a physical state."*
- **Retired notation throughout** — X₁, Y₁, Z₁, "Rₙ operators," "substrate."
- **Consciousness imported as a mechanism** — "observer-field coupling," "configuring consciousness as a measurement apparatus," with predictions offered about meditation states. Physics: *"No entry: consciousness. Nothing in the skeleton selects experience."*
- **常 read as "eternal"** — the reading the register-marker gloss exists to refuse.

**Newer is not better in this set, and the filename says the opposite.** Four files carry `_clean_`
(chapters 8, 37, 40, and one more); only chapter 40 was checked here.

## 4. The condensation lineage, and what it cost

Chapter 1 exists at four lengths: **13.0 KB** (Set B and Set C's 11-26) → **5.9 KB** (Set C, 12-05 and
12-07) → **4.3 KB** (site). Roughly a third survives.

It was not only loss. Set C's 12-05 key-terms table assigns **常無 :: P₀** and glosses it *"absolute
void before distinction operates."* That is the **retired P₀ typing** — v9 re-typed P₀ as the master
pair at equality, *"explicitly not indistinction, which is only one side."* The site version dropped
those assignments. That drop was correct and looks deliberate.

So the condensation did real editorial work. What it also dropped, at least on chapter 1, is the
worked exposition — Set B opens with the potter's hands forming a boundary and both sides appearing at
once, which is the co-emergence argument in one paragraph of physical description and is nowhere in
the chains.
