# v0.971 vs v0.972 — which copy is live?

Asked for before editing either. Run 2026-08-02 on `research-archive`.
Compared `archive/rsm-versions/v0.971/` (95 files) against `archive/rsm-versions/v0.972/` (53 files).

## The short answer

**Neither folder is a superset. You need both.**

- Where a file exists in **both** → they are the **same document**. 44 of 46 differ only in the
  NotebookLM export header (`notebook:` label and `source_id:` UUID); the prose is byte-identical.
  Edit either; prefer **v0.972** so the stamp matches the later export.
- Where a file exists in **v0.971 only** (48 files) → **v0.971 is the only copy.** It was dropped
  from the v0.972 export, not superseded.
- **Six files were genuinely revised** and re-dated `2025-12-07` in v0.972. There, **v0.972 wins.**
- **Two shared chapter files gained content** in v0.972 (pure additions, nothing removed).

Reminder from the catalog: `v0.971`/`v0.972` are **NotebookLM notebook version labels, not RSM
versions.** Both export the same Nov–Dec 2025 working layer.

## Working rule

1. Editing one of the **six revised** files → **v0.972**.
2. Editing `chapter05` or `chapter40` → **v0.972** (it has the observation-stances section).
3. Editing anything else present in **both** → either; prefer v0.972 for the matching stamp.
4. Editing anything in the **v0.971-only** list → **v0.971 is it.** No newer copy exists.
5. Before any edit, `ls` both folders for the basename. The numeric prefixes differ between
   folders (`007-` vs `006-`), so match on the name after the index, not the whole filename.
