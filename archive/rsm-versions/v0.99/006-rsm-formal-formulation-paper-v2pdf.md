Formal Formulation of the Recursive Structural Model (RSM) 
A preferred-time effective field theory on a punctured spatial manifold 
1. Assumptions and topological regime 
The Recursive Structural Model (RSM) is formulated as a preferred-time effective field theory on a punctured spatial manifold. The defining premise is that the local paradoxical center P_n is not an accessible point of the configuration space. Stable frames therefore inhabit a punctured domain rather than a simply connected one. 
Omega_n = R^3 \ M_{P_n} 
Here M_{P_n} is the defect manifold associated with the excluded center. For a line defect, such as the z-axis, the punctured space has nontrivial winding class pi_1(R^3 \ line) ~= Z. In the RSM, the U(1) phase structure of the emergence field is interpreted as the local EFT representation of winding around the puncture, rather than as a fundamental charge symmetry. 
Operationally, one may either define the fields directly on the punctured domain Omega_n, or define them on all of R^3 and enforce vanishing support on M_{P_n} through a puncture-support constraint. These two formulations are intended to represent the same structural exclusion. 
2. The RSM action 
The total Lagrangian density is written as a sum of substrate, emergence, recursion, and puncture-support sectors. 
L_RSM = L_P + L_O + L_Z + L_C 
2.1 Substrate sector 
L_P = -(1/2) d_mu P d^mu P - (1/2) m_0^2 P^2 + (lambda_0/4!) P^4 
This sector sets the baseline threshold for frame emergence. 
2.2 Emergence sector 
L_O = sum_i [ i hbar O_i^dagger D_t O_i - (hbar^2/2 m_fold) (D_a O_i)^dagger (D^a O_i) - (V_fold(r) + g_1 P^2) |O_i|^2 ] 
D_t = partial_t + i (g_rec / hbar) Z_0 D_a = partial_a + i (g_rec / hbar) Z_a 
V_fold(r) = A (r - r_fold)^2 + B / r^alpha, A > 0, B >= 0, alpha > 0 
The finite-radius folding potential provides outward confinement together with an inward shaping stiffness, while the covariant derivatives encode the emergent U(1) phase transport generated by winding around the puncture. 
2.3 Recursion sector 
L_Z = -(1/4) F_{mu nu} F^{mu nu} + (1/2) beta_rec Z_mu Z^mu F_{mu nu} = partial_mu Z_nu - partial_nu Z_mu 
This is a Proca-type realization of the recursion or circulation field. 
2.4 Puncture-support constraint 
L_C = - lambda(x,t) delta_{M_{P_n}}(x) sum_i |O_i(x,t)|^2 
delta_{M_{P_n}}(x) = integral d sigma delta^(3)( x - X(sigma) )
Variation with respect to the multiplier lambda enforces vanishing emergence density on the defect support. This is the EFT implementation of the punctured geometry. 
3. Equations of motion 
d_mu d^mu P - m_0^2 P + (lambda_0/6) P^3 - 2 g_1 P sum_i |O_i|^2 = 0 
i hbar D_t O_i = [ -(hbar^2 / 2 m_fold) D_a D^a + V_fold(r) + g_1 P^2 + lambda(x,t) delta_{M_{P_n}}(x) ] O_i 
partial_nu F^{nu mu} + beta_rec Z^mu = g_rec J^mu 
delta_{M_{P_n}}(x) sum_i |O_i|^2 = 0 
These equations define the coupled substrate, emergence, circulation, and puncture-support dynamics of the frame. 
4. Axisymmetric ansatz and radial reduction 
To exhibit a stable frame, consider a static axisymmetric configuration in cylindrical coordinates (r, theta, z), with defect manifold equal to the z-axis, M_{P_n} = {r = 0}. Take a single emergence mode with winding number n in Z: 
O(r,theta,t) = phi(r) exp(i n theta) exp(-i omega t) 
Assume translational symmetry along z, vanishing temporal recursion potential in the static frame, Z_0 = 0, and a purely azimuthal recursion field Z = Z_theta(r) e_theta. Then 
D_theta O = i [ n/r + (g_rec / hbar) Z_theta(r) ] O 
For a static background substrate P = P(r), the emergence equation reduces to the radial equation 
omega phi(r) = [ -(hbar^2 / 2 m_fold) ( d^2/dr^2 + (1/r) d/dr - ( n/r + (g_rec/hbar) Z_theta(r) )^2 ) + V_fold(r) + g_1 P(r)^2 + lambda(r) delta(r) ] phi(r) 
The azimuthal Proca equation becomes 
d^2 Z_theta/dr^2 + (1/r) d Z_theta/dr - (1/r^2) Z_theta - beta_rec Z_theta = - g_rec J_theta(r) 
J_theta(r) = (hbar / m_fold) [ n/r + (g_rec/hbar) Z_theta(r) ] phi(r)^2 
4.1 Nondimensionalization 
x = r / r_fold E_0 = hbar^2 / (2 m_fold r_fold^2) O(r,theta,t) = phi_0 psi(x) exp(i n theta) exp(-i omega t) a(x) = (g_rec r_fold / hbar) Z_theta(r) 
tilde(omega) = (hbar omega - g_1 P_0^2) / E_0 kappa^2 = beta_rec r_fold^2 gamma ~ g_rec^2 r_fold^2 phi_0^2 / (m_fold E_0) 
psi'' + (1/x) psi' + [ tilde(omega) - tilde(V)(x) - ((n + a)^2/x^2) - tilde(lambda)(x) delta(x) ] psi = 0 
a'' + (1/x) a' - (1/x^2) a - kappa^2 a = - gamma ((n+a)/x) psi^2 
The shell-localized frame is controlled by the confinement parameters A, B, alpha, the screening scale kappa, the circulation backreaction gamma, and the discrete winding number n. 
4.2 Boundary conditions 
- Core: psi(0) = 0 and a(0) = 0. For n != 0, regularity implies psi(x) ~ x^{|n|}. 
- Fold shell: the density attains a local maximum near x = 1 where the folding potential has its minimum.
- Exterior: psi(x) -> 0 rapidly as x -> infinity, while a(x) decays with screened Proca tail proportional to K_1(kappa x). 
4.3 Local analysis near the puncture 
Assume a(x) is regular at the origin, a(x) ~ x^sigma with sigma > 0, so a(0) = 0. Then near x = 0 the local competition is between the angular barrier and the inverse-power core term tilde(V)(x) ~ B / x^alpha. 
psi'' + (1/x) psi' - [ n^2/x^2 + B/x^alpha ] psi ~= 0 
For mild inner shaping, alpha < 2 or B -> 0, the equation reduces to the Cauchy-Euler form, giving indicial equation nu^2 - n^2 = 0 and regular local behavior 
psi(x) ~ x^{|n|} 
The decisive case is n = 0. In that sector, the regular local solution generically behaves as 
psi(x) ~ C_0 + O(x^2) 
so the differential equation alone does not forbid nonzero core support. The puncture-support constraint is therefore essential: it is the unique mechanism enforcing psi(0) = 0 independently of energetic contingencies. 
For sufficiently singular shaping, alpha > 2, the inverse-power core dominates and yields a rapidly decaying irregular solution with WKB-like suppression, faster than any power as x -> 0. 
The homogeneous azimuthal Proca equation near the core gives 
a(x) = C_1 x + C_2 x^(-1) 
and physical regularity sets C_2 = 0, so the circulation field vanishes smoothly at the puncture. 
4.4 Parameter regimes and shell existence 
- Folding geometry (A, B, alpha): A > 0 gives outer confinement; B and alpha set inward shaping stiffness. B is not needed for exclusion itself, but for radial localization quality and inward resistance of the shell. 
- Circulation backreaction (gamma): weak coupling gives passive circulation; strong coupling induces an effective angular barrier through (n+a)^2/x^2 and can broaden or destabilize the shell. 
- Screening scale (kappa): large kappa gives tightly screened circulation; small kappa approaches a long-range massless tail. 
- Eigenvalue structure: for fixed parameters and winding n, localized shell states arise only for discrete admissible values of tilde(omega) when the effective radial operator is confining and self-adjoint under the imposed boundary conditions. 
4.5 Existence and stability of persistent frames 
The persistent frame can be cast as a variational problem. In the axisymmetric sector, the shell corresponds to a minimizer of an effective one-dimensional energy functional subject to puncture exclusion and asymptotic decay. 
Proposition 1 (existence of localized shell solutions). Assume: 
- Outer confinement: A > 0 
- Inner shaping: B >= 0, alpha > 0 
- Massive screening: beta_rec > 0, equivalently kappa > 0 
- Real circulation coupling: gamma >= 0
Restrict the admissible state space to functions satisfying the essential boundary conditions 
psi(0) = 0, a(0) = 0, psi(x) -> 0, a(x) -> 0 as x -> infinity 
Then, for any integer winding sector n in Z, there exists a discrete spectrum of eigenvalues tilde(omega) for which localized finite-energy axisymmetric solutions exist. 
Proof outline via variational principle. The radial equations are the Euler-Lagrange equations of the effective energy functional 
E[psi,a] = integral_0^infinity x dx { |psi'|^2 + ((n+a)^2/x^2) |psi|^2 + tilde(V)(x) |psi|^2 + (1/2 gamma) [ (a')^2 + a^2/x^2 + kappa^2 a^2 ] } 
Because A > 0, the outer wall is strictly confining and controls the large-x behavior. At the lower boundary, the admissible test space already encodes psi(0) = 0, preventing divergence from the inverse-square barrier and respecting puncture exclusion. Under these assumptions the functional is coercive and bounded from below on the appropriate weighted Sobolev space, so a minimizing configuration exists in each winding sector. The corresponding Euler-Lagrange equations recover the dimensionless shell system. 
Proposition 2 (stability and the Wu Wei state). The minimum-energy solutions represent topologically and energetically stable frames of persistence. 
- Topological protection: a configuration in sector n != 0 cannot continuously unwind through the puncture because the excluded core removes the contraction channel. 
- Energetic stiffness: inward perturbations pay steep gradient and shaping costs, while outward perturbations are suppressed by the outer confining wall. 
- Circulatory locking: for gamma > 0, density and circulation mutually regulate one another through the coupled angular term, stabilizing the shell near x = 1. 
5. Physical interpretation 
The formal solution structure enacts the central claim of the Recursive Structural Model. A reality in which the center is structurally non-obtainable does not collapse into chaos. Instead, puncture exclusion removes the forbidden core from the admissible state space, the folding potential shapes a finite-radius shell, and the winding current sources a screened circulation field. Persistent frames therefore appear as localized, annular coordinate structures that cannot legally collapse into the void and need not dissipate into the exterior substrate.
