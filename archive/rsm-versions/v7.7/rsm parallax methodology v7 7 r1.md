## The :: discipline (unchanged, tightened)

`::` denotes imperfect structural correspondence: two expressions from different registers point at the same invariant; neither captures it; each distorts. It forbids substitution, upgrade to identity, congruence by default — and, ruled this cycle, **chaining as transitivity**: A :: B :: C is not a license to read A :: C; each link is priced separately or the chain breaks into separate claims. The glyph-register observation now curing makes the discipline's own point: the equals sign cannot be written without preserving the twoness of what it relates.
