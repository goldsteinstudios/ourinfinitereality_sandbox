## Assumption 0 — regime and scope (stated first, so the reading is not circular)

The model is a preferred-time EFT on a punctured spatial slice

**Ω_n = ℝ³ \ M_{Oₙ}.**

**[R1 — scope.]** The winding structure below requires **Oₙ extended to a line defect** (the
confinement axis / vortex core / disk axis): π₁(ℝ³ \ line) ≅ ℤ, so winding number is well defined.
The **generic point-Oₙ frame** has π₁(ℝ³ \ point) = 0 (the nontrivial class is π₂ ≅ ℤ) and is *not*
modeled here. This is therefore the **Oₙ-centerline regime** — the tokamak/vortex/accretion-axis
family of the physics chain — not the generic frame. Consequence, stated openly: the model is a
valid existence-and-stability proof for shells around a centerline, but it **cannot serve as
evidence for toroidal persistence**, because the centerline is assumed, not derived. It is
scaffolding that is honest about what it assumed.

Standing simplifications: static, axisymmetric, translationally symmetric along the defect.

## Boundary conditions and local analysis

- **Core:** ψ(0) = 0, a(0) = 0; for n ≠ 0, regularity gives ψ(x) ~ x^{|n|}.
- **Shell:** density peaks near x = 1, where V_fold bottoms.
- **Exterior:** ψ → 0 rapidly; a(x) decays with the screened Proca tail ∝ K₁(κx).

Near the core, with a ~ x^σ (σ > 0), the competition is the angular barrier against the inner
shaping term Ṽ ~ B/x^α:
ψ″ + ψ′/x − [ n²/x² + B/x^α ] ψ ≈ 0
For mild shaping (α < 2 or B → 0) this is Cauchy–Euler, indicial ν² − n² = 0, regular behavior ψ ~
x^{|n|}. For α > 2 the inner term dominates with WKB-like suppression faster than any power.

The homogeneous azimuthal equation near the core gives a = C₁x + C₂x^{−1}; regularity sets C₂ = 0,
so the circulation field vanishes smoothly at the puncture.

## Existence and stability

**Proposition 1 (localized shell solutions).** Assume A > 0 (outer confinement); B ≥ 0, α > 0
(inner shaping); M_Z² > 0, i.e. κ > 0 (screening); γ ≥ 0 (real circulation coupling). Restrict the
admissible space to
ψ(0) = 0, a(0) = 0, ψ(x) → 0, a(x) → 0 as x → ∞.
Then for each winding sector n ∈ ℤ there is a discrete spectrum of ω̃ admitting localized
finite-energy axisymmetric solutions.

*Variational argument.* The radial equations are the Euler–Lagrange equations of
E[ψ,a] = ∫₀^∞ x dx { |ψ′|² + ((n+a)²/x²)|ψ|² + Ṽ(x)|ψ|² + (1/2γ)[ (a′)² + a²/x² + κ²a² ] }
A > 0 makes the outer wall strictly confining; the admissible space already encodes ψ(0) = 0,
disarming the inverse-square barrier and respecting the exclusion. The functional is coercive and
bounded below on the appropriate weighted Sobolev space, so a minimizer exists in each winding
sector; its Euler–Lagrange equations recover the shell system.

**Proposition 2 (protected persistent frames).** The minimizers are topologically and energetically
stable frames. **[Register: the prior draft named this "the Wu Wei state." The character is
stripped; the topological content is retained.]**
- **Topological protection:** a configuration with n ≠ 0 cannot continuously unwind through the
  puncture — the excluded core removes the contraction channel.
- **Energetic stiffness:** inward perturbations pay steep gradient and shaping costs; outward
  perturbations are suppressed by the confining wall.
- **Circulatory locking:** for γ > 0, density and circulation co-regulate through the angular term,
  stabilizing the shell near x = 1.

## Scope — what this model does not do

- **No parturition.** This is a static single-frame model. It shows why a frame *persists* around
  its Oₙ (topological protection + confinement); it does **not** model Pₙ → Pₙ + O₍ₙ₊₁₎ — the
  nucleation of a child frame whose Oₙ₊₁ is the parent's Pₙ. Modeling parturition needs a
  non-static sector in which a new puncture opens at an occupied seat; that is deferred. **[R3
  consequence: circulation ≠ recursion. The Z field is the orbit, not the birth.]**
- **Centerline regime only** (Assumption 0 / [R1]): the generic point-Oₙ frame is out of scope.
- **P3 throughout.** The topological protection is coherence with the substrate argument, not
  independent evidence for it — the line defect that makes winding possible was assumed.
