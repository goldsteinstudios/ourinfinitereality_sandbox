## **Core Mathematical Framework**

### **Primary Variables:**
- **P₀** = True Void/Unnameable paradox (常道)
- **Pₙ** = Paradox at level n that recurses into O_{n+1}
- **O_{n+1}** = Origin frame emerging from paradox Pₙ
- **Y₁** = First contrast gradient (一 / Heaven-Earth polarity)
- **X₁** = Dimensional space for gradient expression (二 / Balance axis)
- **Z₁** = Structural rotation (三 / Energy/Qi)
- **Rₙ** = Recursive forms/expressions (萬物)

### **Fundamental Relationships:**
- **Paradox-to-Origin**: Pₙ → O_{n+1} (paradox recurses into origin frame)
- **Curved gradient**: Y₁ = 1/X₁ (contrast inversely proportional to dimensional space)
- **Recursive sequence**: P₀ → O₁ → P₁ → O₂ → P₂ → O₃... 
- **Energy-radius**: Z₁(p) ∝ 1/r(p) 
- **Structural inheritance**: X₁ₙ = Bₙ₋₁
- **Paradox preservation**: ∂Pₙ/∂t = 0 (wu wei condition)

## **Chapter-Specific Key Terms**

### **Chapter 1: Fundamental Paradox**
- **道可道，非恆道** - "Dao is dao, [is] not constant dao"
- **名可名，非恆名** - "Name is name, [is] not constant name"  
- 無名/有名 - Uncollapsed vs. collapsed frame
- 妙/徼 - Structural necessity vs. boundaries

**Core insight**: The moment dao can be identified **as dao** (道可道), it has already fallen from pure paradox (P₀) into particular manifestation and therefore cannot be the constant dao (恆道). Pure logical structure: any particular instance cannot be the universal principle.

### **Chapter 2: Co-Emergence**
- 美/惡 - Beauty/ugliness (contrast pairs)
- 善/不善 - Good/not-good (gradient poles)
- 相生/相成 - Mutual arising/completion

### **Chapter 5: Structural Impartiality**
- 天地之間 - Between Heaven-Earth (X₁ dimensional space)
- 橐籥 - Bellows (recursive vessel model)
- 虛而不屈 - Empty yet not collapsed (paradox preservation)

### **Chapter 42: Structural Unfolding**
- 道生一 - P₀ generates Y₁ (first contrast)
- 一生二 - Y₁ generates X₁ (dimensional space)
- 二生三 - X₁ generates Z₁ (rotation)
- 三生萬物 - Z₁ generates Rₙ (all forms)
